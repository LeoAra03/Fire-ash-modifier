# Ausencias de personajes notables — registro de decisión (FASE 033)

Este registro evita que la ausencia de un personaje del juego base quede al
azar. Una entrada es válida solo si explica la expectativa, la decisión y la
consecuencia narrativa. La ausencia no se marca como defecto únicamente por no
aparecer: se contrasta con el arco que el DLC pretende contar.

| Personaje o grupo | Dónde se esperaba | Decisión | Motivo / sustituto | Regresión |
|---|---|---|---|---|
| Personajes del juego base no necesarios para el arco | Regiones y emisiones del postgame | `pending_review` | Completar tras leer el arco completo en orden; no inventar una aparición solo para llenar una lista | `manual_pending` |
| Aliados nuevos de cada dimensión | Campañas y retorno al hub | `pending_review` | Verificar que cada promesa de ayuda tenga aparición o explicación de ausencia | `manual_pending` |
| Personajes invitados de ROMs | Regiones declaradas como invitadas | `excluded_by_policy` | No se redistribuyen assets ni diálogos de las ROMs; solo se conserva el contrato estructural autorizado | `static_policy` |

## Regla

No se presenta una ausencia como canon ni como error hasta que una revisión de
la historia y un playtest indiquen que rompe una promesa. Toda decisión final
necesita una frase de motivo, su ubicación y una prueba de regresión.
