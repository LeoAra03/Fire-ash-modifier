## Reglas de decisión

- La hipótesis y el límite de tiempo se escriben antes del cambio.
- Cada cambio tiene una medición antes y después.
- Una conclusión solo se adopta tras un segundo grupo independiente.
- Un resultado negativo se conserva y puede provocar reversión.
- Cinco participantes aportan una señal indicativa, no una validación estadística.
- El registro no almacena datos personales.

## Medidas

| Medida | Unidad | Definición |
|---|---|---|
| time | seconds | tiempo desde la instrucción hasta completar el objetivo; registrar mediana y rango |
| stuck | events | atasco cuando la persona nueva permanece más de 120 segundos sin progreso ni decisión |
| defeats | count | derrotas contra un jefe desde el mismo estado inicial |
| abandonment | map_or_minute | punto donde la persona deja de jugar o expresa que no continuará |
| comprehension | rubric_0_to_3 | recuerdo cinco minutos después: 0 no recuerda, 1 detalle aislado, 2 idea correcta, 3 objetivo y consecuencia correctos |
| discovery | count | hallazgos opcionales encontrados sin guía |
| satisfaction | rubric_1_to_5 | valoración declarada del final/recompensa, siempre acompañada de un porqué |
