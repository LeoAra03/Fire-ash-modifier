# Reporte de errores para jugadores

No incluyas datos personales. Copia solo la información necesaria para
reproducir el problema.

```text
Título breve:
Versión/commit o nombre del ZIP:
Sistema/dispositivo:
¿Game.exe, Kirin, Android u otro?:
Mapa y coordenadas aproximadas:
Pasos desde el último guardado:
Resultado esperado:
Resultado observado:
Mensaje exacto:
¿Se reproduce al recargar?:
Captura o vídeo (sin datos personales):
Hash del archivo de partida si es imprescindible:
```

Clasifica la gravedad: bloqueante (no se puede continuar), grave (se pierde
contenido o progreso), leve (hay rodeo) o cosmético (presentación).
